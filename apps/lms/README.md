## 🚨 Project Overview

This repository contains the complete source code for a powerful LMS SaaS platform built using **Next.js**, **Supabase**, **Vapi**, **Stripe**, and more.

It features everything needed to launch an AI-integrated learning platform — from authentication, real-time voice AI tutoring, and payments to responsive design and a modern UI.

## 🤖 Introduction

Build your own learning management SaaS platform with voice AI agents, tutor creation, secure login, subscriptions, and bookmarks. Designed and developed entirely by **Vibhu Vishwakarma**, this application brings interactive, real-time tutoring into your browser using **Vapi** and other powerful tech.

## ⚙️ Tech Stack

- **Next.js** – Full-stack React framework
- **Supabase** – Real-time database and backend
- **Clerk** – Authentication and billing
- **Stripe** – Payment gateway integration
- **Tailwind CSS** – Modern utility-first styling
- **shadcn/ui** – Accessible and polished UI components
- **Vapi** – AI-powered voice interaction layer
- **Zod** – Type-safe data validation
- **Sentry** – Error tracking and monitoring
- **TypeScript** – Safer and scalable development
